# Project description

Echo Ledger: Burrow Protocol is an original community game for Squeekchain Genesis. Guide a mouse courier beneath Squeektoshi's real hamster wheel, record your footsteps, and coordinate looping echoes to restore the burrow's ledger. Live wheel activity powers echo energy; confirmed settlements trigger tactical Surges; real distance unlocks lore. Explore three colorful biomes, outwit five threat types, and defeat the Auditor General using simultaneous echoes. Eight upgrade branches, collectible memories, achievements, a codex, Shared Block challenges, and detailed run summaries support repeat play. Desktop and touch controls include clearly labeled offline simulation. No wallet is required. Built by 0xRicher. Not officially affiliated.
